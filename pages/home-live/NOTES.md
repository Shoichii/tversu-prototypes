## Что поднять в system (повторилось у нескольких)
- `ul[role=list] { padding: 0 }` в base.css перебивает одиночные классы (a, e, f, g) и `svg { max-width: 100% }` сжимает декоративные SVG (g) — понизить специфичность через `:where()`.
- `transform-box: fill-box` в CSS ломает GSAP-трансформы SVG (e) — предупреждение в motion.css; `data-m="draw"` со шторкой на самом элементе не видит IntersectionObserver (f).
- three-stage.js: авторегулятор разрешения для программного рендера (b), режим «стоять, когда сцена не двигается» (f), `RoundedBoxGeometry` в vendor/three/addons (b).
- Компоненты: карточка с вырезом под кнопку (e, f), липкая мобильная кнопка, прячущаяся у формы (c, f), тень материала через `@property --lift` (g), кнопка-наклейка `.btn-stk` и перфорированная марка (a, c), раскрытие карточки из плитки с возвратом фокуса (d), сборка цифр из геометрии и табло-перекидка (c).
